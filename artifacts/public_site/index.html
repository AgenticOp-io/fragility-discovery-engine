Run adversary search scenarios on live infrastructure, then explore results in the browser. No install on your machine — everything executes on this server.

Tools

⚡

Run a scenario

Submit a fragility search. Choose a domain, set parameters, and the engine finds the worst-case adversary schedule. Results open directly in the viewer.

 ▶

Replay viewer

Step through a scenario frame by frame. See how shocks propagate, when metrics cross thresholds, and what the system state looks like at each timestep.

 ◎

Pareto viewer

Explore the attacker-defender trade-off frontier produced by a co-evolution run. Each point is a non-dominated adversary schedule on the archive.

 ⛓

Attribution viewer

Counterfactual chains that show which shock interventions drove collapse. Trace causality from individual schedule steps back to the fragility score.

 ⊞

Composite viewer

Compare up to five fragility domains side by side in a single audit view. Load a composite JSON or use the built-in presets.

 📖

Documentation

Installation guide, domain tutorials, algorithm provenance, CLI reference, and architecture overview — all in one place.
