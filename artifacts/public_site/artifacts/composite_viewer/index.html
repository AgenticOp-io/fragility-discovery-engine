Composite viewer

Side-by-side fragility scorecard for one shared scenario, run through several different domain models at once (peg, network contagion, resource cascade, service backlog, liquidity ladder). One row per domain — same shock, different lenses.

What the table shows
  • kernel — which domain model was used (aggregate, network, resource_cascade, service_backlog, liquidity_ladder).
  • integral instability — total accumulated stress over the run; higher means more fragile under this shock.
  • collapsed — did this domain actually break? Green = no, red = yes.
  • attack cost — what the attacker had to spend.
  • collapse timestep — when the break happened, if it did.

This is a metric snapshot, not a timeline — for a step-by-step replay of a single domain, use the Replay viewer.

How to use it
  • Pick a preset (twin / triple / quad / penta composite) or load your own fragility-institutional-composite-v1…v4 JSON.
  • Compare rows: domains where instability spikes but collapse stays green are the ones with the smallest safety margin.
